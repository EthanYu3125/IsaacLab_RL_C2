# Unitree G1 期中競賽｜專案 README

本專案使用 Isaac Lab 3.0.0、skrl 與 PPO 訓練 Unitree G1 人形機器人。競賽目標是在保持平衡、不跌倒的情況下，朝目標前進並完成競速任務。

本文件依據《期中競賽說明.pptx》整理，供參賽者與 Codex 閱讀。指令、預設參數與限制均以提供的簡報為依據；實作前仍須核對專案中的檔案、介面與允許修改的區塊。

  --task Miislab-Humanoid-Gait-Rl-G1-Direct-v1 \

## 7. 獎勵函式與預設權重

### 7.1 修改位置與計算方式

獎勵設計分為兩個部分：

- `RewardsCfg`：定義獎勵權重及相關設定。
- `compute_rewards()`：計算各個獎勵項目，並回傳對應字典。

簡報中的總獎勵公式為：

```text
totalReward = sum(rewardValue * rewardWeight) * step_dt
step_dt = 0.02 秒
```

對非負的獎勵項目值而言，正權重提供獎勵，負權重提供懲罰，零權重使該項目不影響總獎勵。若自訂項目可能為負值，須一併檢查項目值與權重相乘後的效果。

新增項目時須沿用既有程式的權重與 `step_dt` 彙總方式，避免重複乘上權重或時間間隔。此為公式實作注意事項。

### 7.3 新增獎勵範例：減少垂直彈跳

此範例來自簡報，目的為懲罰機體座標下過大的垂直線速度。下列片段須分別加入既有程式的允許區塊，不能取代整個類別或函式。

在 `RewardsCfg` 中新增權重：

```python
lin_vel_z_l2 = -0.2
```

在 `compute_rewards()` 中計算每個環境的垂直速度平方：

```python
linVelZ = torch.square(data.root_lin_vel_b.torch[:, 2])
```

在既有回傳字典中加入項目：

```python
"lin_vel_z_l2": linVelZ,
```

設定欄位與字典鍵均須使用 `lin_vel_z_l2`。範例中的區域變數採 lower camelCase，既有設定鍵維持原名。

## 9. 實驗與比較流程

簡報建議依序執行以下步驟：

1. **修改**：一次調整一個獎勵項目或權重。
2. **訓練**：執行訓練並保留模型及指標。
3. **回放**：載入 checkpoint，觀察 G1 的實際步態。
4. **比較**：記錄改善、退步及其他觀察結果，再決定下一次調整。

建議為每次實驗記錄修改內容、訓練設定、checkpoint 路徑及回放觀察，以利撰寫報告。此為紀錄建議，簡報未規定固定的實驗表格格式。
